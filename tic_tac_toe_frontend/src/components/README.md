# Tic Tac Toe UI Components

- **Board.js** – The main game board (3x3), uses color scheme, responsive, `board`, `onCellClick`, `isMyTurn`, and winner highlighting.
- **GameLobby.js** – Displays current and open games to join, lets user start new.
- **Sidebar.js** – Tabbed history/leaderboard listing, with callbacks to select/click a game.
- **AuthModal.js** – Lightweight modal for login/signup, overlays via portal.

All components are minimal, modern, and use only vanilla React and the established color scheme.
